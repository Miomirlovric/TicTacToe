# TicTacToe
## Description
* TicTacToe is a two player board(4x4) game made with MFC

## Rules
* Player X moves first
* Player O moves second
* Win condition is to have three of your characters in a row,column or in a diagonal line

## Playable characters
* X
* O

## Controls
* left button click - sets player X character
* right button click - sets player O character
* restart button - starts the game again
* exit button - exit game

## Setup
* no additional setup is needed
